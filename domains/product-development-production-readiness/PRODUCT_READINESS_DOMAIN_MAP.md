## Core lifecycle state model
Concept -> proof of concept -> prototype -> MVP / engineering prototype -> EVT-like engineering validation -> DVT-like design validation -> PVT-like production validation -> pilot -> controlled ramp -> stable serial production.

These labels are organization-specific; the Atlas should preserve the underlying objective/evidence rather than assume universally identical gate names.

## Engineering principle
A product can be technically functional and still be unready for production. Product readiness and manufacturing-system readiness are coupled but distinct evidence states.

## Master decision object
### D-PDR-MASTER-001 — Is the product and production system ready to advance?
Inputs: design maturity, requirements verification, production-intent materials/processes, tooling, suppliers, test/inspection readiness, configuration control, quality evidence, reliability evidence, cost/capacity and open risks.

Output: advance / conditional advance / hold + evidence gaps + required actions + assumptions.

## Integrity rule
Do not infer production readiness from prototype success, shipment urgency or calendar milestone alone.
