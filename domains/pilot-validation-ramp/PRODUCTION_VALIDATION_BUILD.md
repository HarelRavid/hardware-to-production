# 5.2 Production Validation Build

status: Researching
provenance: [GNR]

## Scope
A controlled build intended to demonstrate that the released or near-released product can be manufactured using representative production resources, methods, personnel, suppliers and controls.

## Validation dimensions
- released/effectivity-controlled design
- MBOM
- routing
- production tooling
- production equipment
- released WI/standard work
- trained/qualified operators
- intended suppliers/materials
- control plan/PFMEA
- capable measurement/test systems
- traceability/genealogy
- representative production rate

## Evidence objects
- build traveler/genealogy
- defect log
- operation-level yield
- FPY/RTY
- cycle-time distribution
- downtime/stoppage
- rework/touch labor
- scrap
- test results
- deviations
- engineering interventions
- supplier issues
- open actions

## Engineering principle
Production validation validates a defined production configuration. If the configuration changes materially after the build, the validity of prior evidence must be reassessed rather than assumed to transfer automatically.

## Decision objects
### D-RAMP-PV-001 — Is the build sufficiently production representative to support validation?
### D-RAMP-EVID-001 — What evidence must be collected during the build?
### D-RAMP-INT-001 — How are engineering interventions classified and counted?
### D-RAMP-REVAL-001 — Does a post-build change require partial or full revalidation?

## Invalid shortcuts
- excluding reworked units from yield without disclosure
- reporting only final pass rate
- ignoring engineering touch labor
- changing process parameters without configuration record
- substituting non-intent material/tooling without limiting conclusions
