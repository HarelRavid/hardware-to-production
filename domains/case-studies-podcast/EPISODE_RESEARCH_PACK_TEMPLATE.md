# 10.9 Episode Research Pack Template

status: Researching
provenance: [GNR]

## Purpose
Define the minimum structured research package required before an episode moves from topic idea to scriptable, evidence-grounded content.

## Episode Research Pack
### 1. Episode identity
- episode ID/title
- PODCAST_MAP position
- mapped WBS domains
- target listener
- main engineering question

### 2. Listener promise
What practical decision, mental model or failure mode should the listener understand better by the end?

### 3. Core decision framework
- decision object(s)
- inputs/assumptions
- options
- tradeoffs
- output/recommendation logic

### 4. Engineering claims
For each episode-critical claim:
- claim ID
- exact scoped wording
- evidence maturity
- supporting sources
- contradicting/conflicting sources
- applicability limits
- confidence/open question

### 5. Standards/regulatory content
- standard ID/revision
- applicability
- relevant clauses
- normative/informative role
- quotation/paraphrase boundaries

### 6. Case studies
- case ID
- mechanism
- evidence
- context
- lesson
- transfer limits

### 7. Quantitative examples
- assumptions
- formulas/models
- units
- data source
- sensitivity/range
- warnings against overgeneralization

### 8. Common mistakes/myths
Each myth must map to evidence/claim rather than rhetorical assertion.

### 9. Open questions/conflicts
Questions not resolved by the evidence stay visible and may become explicit episode discussion.

### 10. Episode narrative skeleton
Hook -> problem -> mental model -> evidence -> decision framework -> case -> practical application -> failure modes -> takeaway.

### 11. Visual/show-note assets
- diagrams/tables needed
- standards/source links
- books/papers
- definitions/glossary
- further reading

### 12. Readiness review
- evidence critical claims verified?
- contradictory evidence represented?
- quantitative examples checked?
- standards current/applicable?
- case mechanisms bounded?
- listener takeaway actionable?

## Status gate
A Research Pack may be Draft / Researching / Verified / Podcast Ready. Script drafting should normally begin only after the pack is sufficiently evidence mature for the episode's risk/technical depth.

## Integrity rule
Narrative convenience must not override unresolved engineering uncertainty.
