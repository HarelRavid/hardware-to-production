# 3.6 Machining — Source Index

## Standards / primary sources

### ISO 230-2:2014
Test code for machine tools — Part 2: determination of accuracy and repeatability of positioning of numerically controlled axes.
Use: machine-axis positioning capability, acceptance/periodic verification context.
Status: Published / confirmed according to ISO catalogue.

### ISO 230-7:2015
Test code for machine tools — Part 7: geometric accuracy of axes of rotation.
Use: rotary-axis/spindle error-motion context for turning and multi-axis machining.

### ISO 230-12:2022
Test code for machine tools — Part 12: accuracy of finished test pieces.
Use: separates machine geometric contributors from other contributors to machined test-piece error; directly relevant to machine-vs-part capability claims.

### ISO 13399-1:2006
Cutting tool data representation and exchange — overview, principles and general information model.
Use: standardized cutting-tool information architecture and digital tool data.

### ISO/TS 13399-2:2021
Reference dictionary for cutting items.
Use: standardized cutting-item descriptions/properties.

### ISO/TS 13399-3:2021
Reference dictionary for tool items.
Use: standardized tool-item descriptions/properties.

## Evidence rules
1. Published machine accuracy is not accepted as a finished-part tolerance without process context.
2. Vendor cutting recommendations remain manufacturer/tool-specific guidance unless corroborated.
3. Numerical cutting data must retain work material, tool, geometry, machine/process and objective context.
4. Current revision/status of standards must be checked before publication or podcast use.

## Provenance
This index structure and summaries are GNR syntheses; external standards remain the primary evidence.
