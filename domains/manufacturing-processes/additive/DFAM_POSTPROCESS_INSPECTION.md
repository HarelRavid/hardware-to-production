# 3.11.4 DfAM, Post-Processing & Inspection

status: Researching
provenance: [GNR]

## DfAM objects
- part consolidation
- topology optimization
- lattice structures
- conformal/internal channels
- mass reduction
- function integration
- support minimization
- self-supporting geometry
- escape/cleanout access
- machining allowance
- datum pads
- sacrificial features
- serialization/embedded identification boundary

## Post-processing chain
Build -> depowder/wash/clean -> support removal -> thermal treatment -> HIP/debind/sinter where applicable -> machining/finishing -> cleaning -> inspection -> functional test.

The chain is process-specific; not every step applies to every AM family.

## Inspection objects
- visual
- dimensional metrology
- CT/X-ray
- ultrasonic boundary
- density/porosity measurement
- metallography
- surface roughness
- hardness
- tensile/fatigue coupons
- witness specimens
- leak/pressure testing
- internal-channel verification

## Key principle
Design freedom without verification access can create unmanageable production risk. Inspection and cleaning strategy therefore belong in DfAM, not only after design release.

## Decision objects
### D-AM-INSP-001 — How will critical internal geometry be verified?
### D-AM-CLEAN-001 — Can all trapped feedstock/process residue be removed and proven removed?
### D-AM-DATUM-001 — Which datums/surfaces should be generated by AM versus finish machining?
### D-AM-CONS-001 — Does part consolidation improve the complete lifecycle or only reduce part count?

## Cross-links
DfAM <-> DFA
Post-processing <-> machining
Internal channels <-> CT/inspection
Surface integrity <-> fatigue/sealing
Part consolidation <-> joining/serviceability

Quantitative design rules remain evidence-scoped.
