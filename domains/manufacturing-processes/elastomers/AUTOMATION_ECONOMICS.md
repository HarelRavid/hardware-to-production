# 3.9.6 Elastomer Automation & Production Economics

status: Researching
provenance: [GNR]

## Automation objects
- automated material feeding
- preform preparation
- injection/transfer dosing
- mold loading/unloading
- demolding
- flash removal / deflashing
- cryogenic deflashing
- vision inspection
- dimensional inspection
- post-cure handling
- seal sorting/counting
- traceability

## Production variables
- cavity count
- cure time
- mold temperature
- machine utilization
- changeover
- scrap/rework
- flash/trim labor
- post-cure time
- inspection burden
- tool maintenance
- compound shelf/storage constraints

## Cost model
Cost per good part = material + conversion/machine + tooling amortization + labor + cure/post-cure + trimming/deflashing + inspection + scrap/rework + maintenance + handling/packaging + quality/traceability overhead.

## DFM questions
- Does geometry drive manual deflashing or secondary trimming?
- Can cavity count increase without creating thermal/fill/cure variation?
- Is post-cure the actual production bottleneck rather than molding cycle time?
- Can handling/inspection be automated without deforming compliant parts?
- Is a custom molded seal economically justified versus a standard seal?

### D-ELAST-MAKEBUY-001 — Standard purchased seal, custom supplier part or in-house molded part?
