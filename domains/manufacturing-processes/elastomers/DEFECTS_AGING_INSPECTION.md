# 3.9.4 Defects, Aging & Inspection

status: Researching
provenance: [GNR]

## Defect taxonomy
- flash
- short fill
- trapped air / voids
- flow marks
- knit lines
- contamination
- surface tearing
- mold fouling marks
- undercure / overcure
- dimensional distortion
- bond failure
- insert mislocation

## Aging mechanisms / service changes
- compression set
- stress relaxation
- hardening / softening
- swelling
- extraction / leaching
- thermal aging
- oxidation / ozone attack
- UV exposure
- fluid/chemical exposure
- permeation
- fatigue / flex cracking

## Inspection objects
- visual inspection
- dimensional inspection
- hardness / durometer
- compression set testing
- tensile/elongation
- tear
- density
- cure-state proxies
- leak testing
- bond/pull testing
- surface inspection

## Engineering questions
- Which defects are appearance-only and which are functional?
- Which material properties must be measured after aging, not only initially?
- Can visual inspection detect the failure modes that matter?
- Does a change in compound supplier, cure system or post-cure require revalidation?

## Qualification chain
Material specification -> compound lot -> molding/extrusion procedure -> cure/post-cure -> inspection -> aging/environmental validation -> product acceptance.

## Decision objects
### D-ELAST-AGE-001 — What aging validation is required?
### D-ELAST-INSP-001 — What inspection/test strategy is justified?
### D-ELAST-CHANGE-001 — Does this compound/process change require requalification?

## Knowledge integrity
Accelerated aging and compatibility data must preserve test temperature, duration, medium, specimen/product geometry and property measured. No accelerated test is assumed equivalent to field lifetime without validated correlation.
