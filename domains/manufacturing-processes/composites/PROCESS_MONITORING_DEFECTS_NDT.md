# 3.8.8 Process Monitoring, Defects & NDT

status: Researching
provenance: [GNR]

## 3.8.8.1 Process monitoring objects
- vacuum level
- leak rate
- resin temperature
- resin viscosity
- flow-front position
- mold temperature
- tool temperature
- part thermocouples
- autoclave/oven pressure
- cure time/temperature history
- dielectric/cure monitoring
- compaction pressure
- fiber-placement process data

## 3.8.8.2 Defect taxonomy
- voids/porosity
- dry fiber
- resin-rich region
- resin-starved region
- delamination
- wrinkle
- waviness
- fiber misorientation
- foreign object debris
- inclusion
- bridging
- ply drop error
- core crush
- skin-core disbond
- weak/poor bond
- machining delamination
- impact damage
- dimensional distortion

Each defect must preserve: mechanism, process origin, structural relevance, detectability, inspection method, prevention/control, acceptance source, evidence maturity.

## 3.8.8.3 NDT/NDE objects
- visual inspection
- tap testing
- ultrasonic pulse-echo
- through-transmission ultrasonics
- phased array UT
- radiography / CT
- thermography
- shearography
- acoustic methods
- dimensional inspection

## 3.8.8.4 Core principle
NDT selection is defect-, geometry-, material- and criticality-dependent. No method is modeled as a universal detector.

## 3.8.8.5 Decision objects
### D-COMP-NDT-001 — Which inspection/NDT method fits this defect and geometry?
### D-COMP-MON-001 — Which process variables must be recorded?
### D-COMP-DEF-001 — Prevent, monitor or inspect for this defect?

## 3.8.8.6 Production linkage
Process signature -> defect risk -> inspection -> acceptance -> traceability -> feedback/process improvement.

Quantitative detection limits and acceptance thresholds remain standard/customer/material-system scoped.
