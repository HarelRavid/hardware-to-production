# Episode 3 Production Blueprint — What NPI and Industrialization Actually Own

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 1 — Build the Right Hardware Before Production Finds Your Mistakes

## Listener transformation
The listener learns to see NPI/industrialization as a cross-functional evidence-closure system rather than a late handoff or project-management role.

## Narrative hook
Engineering says “the design is done.” Manufacturing receives the package and immediately asks: Which BOM? Which supplier? Which fixture? Which test? Which rework path? Which change is allowed? The handoff fails because the product definition and the production system were never closed together.

## Teaching flow
1. Why late handoff fails.
2. Responsibilities versus job titles.
3. Industrialization domains: configuration, process route, tooling, supplier readiness, CTQs, test, work instructions, traceability, pilot learning, yield/rework, rate, economics and change/effectivity.
4. Explain why NPI should influence decisions while they remain reversible.
5. Build the NPI Ownership Map.
6. Sentinel handoff: working integrated prototype with connector, calibration, source and traceability gaps.
7. Define industrialization exit as evidence for the next commitment, not document completion.

## Listener tool — NPI Ownership Map
For each workstream capture: `Owner → Inputs → Output/evidence → Dependency → Trigger/date → Release authority`.

## DEV/LVP/SVP
DEV: responsibilities may be distributed across generalists. LVP: ownership must become explicit across builds, suppliers and test. SVP: configuration, process, supplier, measurement, rate and release controls must operate coherently.

## Common mistakes
- NPI invited after tooling purchase.
- NPI reduced to schedule tracking.
- Quality asked to “add controls” after design/process choices are frozen.
- Supplier readiness handled independently of engineering change.
- Pilot builds producing units but no learning closure.

## Source/evidence backlog
Source any formal organizational or lifecycle claims only when externally attributed. Keep the responsibility map as internal synthesis.

## Closing handoff
Episode 3 assigns ownership. Episode 4 gives those owners a readiness model that keeps product and manufacturing evidence separate.
