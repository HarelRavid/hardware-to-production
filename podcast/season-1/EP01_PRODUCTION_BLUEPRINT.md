# Episode 1 Production Blueprint — The Product Works. Why Can’t We Manufacture It?

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 1 — Build the Right Hardware Before Production Finds Your Mistakes

## Listener transformation
The listener stops treating “it works” as evidence of manufacturing readiness and learns to decompose the prototype into explicit product, process, supplier, test, configuration, rate and economic claims.

## Narrative hook
Open with a believable build: one engineer assembles a unit in six hours. It passes. The team celebrates. Then ask what happens when the same product must be built by another person, from another lot, using released instructions, at ten units per day. Hand fitting, remembered fixes, lab-only tools, undocumented calibration and hero troubleshooting suddenly become the process.

## Teaching flow
1. Prototype success versus production claim.
2. The hidden work inside a “successful” build.
3. Manufacturing debt: manual rescue, undocumented assumptions, nonrepresentative suppliers/processes.
4. Introduce the Manufacturability Evidence Gap Map.
5. Walk through product configuration, CTQs, route/window, suppliers, measurement, test, tooling, work method, traceability, yield/rework, capacity, cost and change.
6. Sentinel example: one good sensor node versus a repeatable low-volume build.
7. First Industrialization Review method.
8. Close: the next build should retire evidence gaps, not merely create another unit.

## Listener tool — First Industrialization Review
For each dimension record: `What prototype proved → What remains unproved → Consequence → Next evidence → Owner`.
End the review by selecting the five highest-consequence gaps.

## DEV/LVP/SVP
DEV: one-off rescue is acceptable if visible. LVP: repeatable work, identity, measurement and failure capture become necessary. SVP: sustainable accepted throughput, capability, controlled suppliers/equipment and economics must coexist.

## Common mistakes
- “We built three, so the process is proven.”
- Treating final PASS as evidence that rework did not happen.
- Using cycle time from the best operator as capacity.
- Assuming supplier sample quality proves future production capability.
- Freezing the design because the demo worked.

## Source/evidence backlog
Use P2.01–P2.06 and authoritative manufacturing-readiness guidance. Any external readiness terminology remains applicability-controlled. Quantitative examples must distinguish illustrative Sentinel data from field data.

## Closing handoff
Episode 1 creates the gap. Episode 2 asks what the current build actually represents; Episode 3 asks who owns closure.
