## Listener tool — Assembly Risk Walk
Operation → orientation → access → sequence → identification → controlled input → fixture/datum → hidden defect → verification → rework/recovery → human dependency → design opportunity.

## Misconceptions
- fewer parts is always better;
- operator error ends the analysis;
- downstream inspection is equivalent to prevention;
- poka-yoke means no training/validation;
- final torque value alone proves a joint.

## Closing action
Watch one assembly operation and list every place where success depends on memory, feel, hidden sequence or one expert trick.
