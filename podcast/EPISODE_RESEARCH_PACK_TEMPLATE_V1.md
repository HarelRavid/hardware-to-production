## 24. Ready-to-advance checklist

### CLAIM SET STABLE
- truth boundaries stable;
- core claim inventory stable;
- audience/lifecycle contract clear;
- no known backbone contradiction.

### EVIDENCE VERIFIED
- relevant P0 verified;
- applicability controlled;
- consequential calculations checked;
- case facts controlled;
- standards/manual acquisition blockers closed or explicitly removed from episode scope.

### TECHNICALLY REVIEWED
- required reviewer competence satisfied;
- critical comments closed;
- source-vs-synthesis boundary intact.

### SCRIPT READY
- core on-air claims selected;
- episode density controlled;
- listener tool finalized;
- narrative can be written without inventing technical truth.

### PODCAST READY
- technical + editorial + source/show-note package passed;
- publication version/date can be archived.
