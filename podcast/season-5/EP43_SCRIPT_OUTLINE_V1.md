## Listener promise
Decompose an operation into functions and assign human, fixture, assisted, robot and vision roles based on actual variation, consequence, recovery and evidence.

## Cold open
[ILLUSTRATIVE] A full robotic cell is proposed for an operation where only one repetitive alignment/dispense function is painful; a fixture plus controlled dispenser removes most loss.

## Misconceptions

- cobot = safe cell;
- vision problem = algorithm problem;
- repeatability = accuracy;
- removing operator judgment always improves robustness.

## Closing action
