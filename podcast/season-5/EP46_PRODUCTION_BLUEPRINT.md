# Episode 46 Production Blueprint — Scaling Without Automating Defects

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 5 — Automation, Data and the Connected Factory
lifecycle: Ramp → SVP
maps_to: MASTER_WBS 8.10

## Listener transformation
Before: sees scale as more machines, more automation and higher rate.
After: uses evidence to decide whether the production system is mature enough to multiply, and identifies what must be stabilized before adding rate or replicas.

## Narrative hook
A team duplicates a production cell to double capacity. Both cells reproduce the same intermittent defect, but now at twice the speed and across twice the WIP. Scaling increased output and simultaneously increased the size of every unresolved failure population.

## Teaching flow
1. Scale multiplies both capability and instability.
2. Reconfirm product/configuration stability.
3. Reconfirm measurement adequacy and process capability.
4. Separate true constraint from local machine utilization.
5. Confirm standard work/tooling/test before duplication.
6. Check defect/rework history and hidden manual rescue.
7. Validate automation abnormal/recovery states.
8. Define release/genealogy across replicated equipment.
9. Scale in controlled increments and watch the moving constraint.
10. Stop expansion when evidence quality degrades.

## Core framework — Scale Readiness Gate
`Stable definition → stable process → adequate measurement → known losses → accepted throughput → controlled rework → qualified equipment → maintenance/recovery → genealogy → staged scale → monitor new constraint`.

## Listener tools
- Scale Readiness Gate.
- Replication Equivalence Check: machine/fixture/software/calibration/material/operator/environment differences and evidence needed before treating cells as equivalent.

## Common mistakes
- cloning equipment before cloning the process definition;
- nominal capacity used as proof of scalable good output;
- unresolved rework normalized as part of the process;
- parallel cells assumed equivalent without validation;
- automation added to a nonconstraint;
- scale program declared complete before the new bottleneck appears.

## Quantitative gate
Capacity/yield/OEE/replication examples require explicit population, time basis and audited arithmetic. System accepted throughput remains the governing economic/rate lens.

## Closing handoff
The first half of Season 5 ends with a controlled automated production system. Episode 47 now asks where its definitions, transactions, execution, quality and machine history should live without creating competing truth.
