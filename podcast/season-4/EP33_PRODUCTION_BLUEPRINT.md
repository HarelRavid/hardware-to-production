# Episode 33 Production Blueprint — Nonconformance, MRB, CAPA and Learning from Failure

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 4 — Quality, Suppliers and the Reality of Scale
lifecycle: LVP → SVP

## Listener transformation
Before: treats a nonconformance as a paperwork item to close.
After: distinguishes containment, disposition, root cause, corrective action and effectiveness, and preserves failure history as population evidence.

## Narrative hook
A failed unit is reworked, retested and marked PASS. Three weeks later the same symptom appears in another lot. The first event was closed operationally but never converted into engineering learning.

## Teaching flow
1. Detect and identify the nonconformance.
2. Contain the affected and potentially affected population.
3. Preserve configuration, lot, process and test evidence.
4. Disposition: rework, repair, use-as-is, scrap, return.
5. MRB as controlled technical/business disposition, not a defect-hiding mechanism.
6. Root cause versus symptom and escape cause.
7. Corrective action versus immediate correction.
8. CAPA scope when system-level action is justified.
9. Verification of implementation and effectiveness.
10. Feed lessons back into design, process, supplier and controls.

## Core framework — Nonconformance Learning Chain
`Detection → containment → affected population → evidence preservation → disposition → root/escape cause → corrective action → change/effectivity → verification → effectiveness → systemic learning`.

## Listener tools
- NCR/MRB Decision Card.
- Repeat-Failure Check: configuration, lot, supplier, operation, equipment, measurement, environment, rework and prior history.

## Common mistakes
- retest-to-pass erasing the original failure;
- containment described as corrective action;
- root cause chosen without evidence;
- use-as-is decisions without requirement/risk authority;
- CAPA opened for every defect or for none;
- effectiveness assumed because an action was completed.

## Source/evidence backlog
Sector-specific MRB authority, CAPA requirements, disposition rules and record retention require exact regulatory/customer applicability. ISO 9001/QMS and regulated-sector requirements must be cited only where applicable.

## Closing handoff
Episode 34 extends the learning loop over time: how production variation and field exposure interact with reliability claims.
