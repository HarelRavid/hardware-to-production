# Episode 32 Production Blueprint — Process Capability, SPC and Knowing Whether Production Is Stable

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 4 — Quality, Suppliers and the Reality of Scale
lifecycle: LVP → SVP

## Listener transformation
Before: uses yield or a capability index as a shorthand for process health.
After: separates stability, centering, spread, specification limits and capability evidence, and knows when a numerical index is not yet decision-worthy.

## Narrative hook
A process reports Cpk > 1.33 and the team celebrates. A control chart shows a clear shift halfway through the run. The number looked reassuring because instability had been compressed into one statistic.

## Teaching flow
1. Variation as population behavior, not isolated bad parts.
2. Common-cause vs special-cause concepts.
3. Control chart purpose: detect changes in process behavior.
4. Specification limits vs control limits.
5. Stability before capability interpretation.
6. Cp/Cpk and Pp/Ppk at a conceptual level; assumptions must be explicit.
7. Measurement adequacy and subgroup/rational-sampling logic.
8. Reaction plans when the process changes.
9. DEV/LVP/SVP maturity: from learning data to monitored production control.

## Core framework — Stability-to-Capability Decision Chain
`CTQ → measurement adequacy → sampling/subgroup logic → time-ordered data → stability assessment → distribution/model assumptions → capability question → index/analysis → reaction plan`.

## Listener tools
- Stability vs Capability Review.
- SPC Reaction Plan Card: signal, immediate containment, process check, affected population, disposition, verification and restart criteria.

## Common mistakes
- capability index on an unstable process;
- control limits treated as specifications;
- high Cpk interpreted as proof of no future defects;
- cherry-picked data windows;
- ignoring measurement-system variation;
- using one universal capability threshold without customer/sector applicability.

## Source/evidence backlog
Exact formulas, confidence treatment, subgroup rules and acceptance thresholds require authoritative statistical/sector sources. AIAG/VDA SPC, ISO statistical standards and customer-specific rules must be edition/applicability controlled.

## Closing handoff
Once a process signal or defect appears, Episode 33 asks how to contain, disposition and learn without confusing unit closure with systemic correction.
