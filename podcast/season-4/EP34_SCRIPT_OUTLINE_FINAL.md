## Misconceptions
- MTBF = lifetime;
- passing qualification proves all field environments;
- component qualification proves system reliability;
- zero failures proves reliability;
- accelerated test always maps to field life;
- field returns can be pooled without context.

## Closing action
For one reliability claim, write the exact population, use profile, failure mechanism and evidence boundary you are actually claiming.
