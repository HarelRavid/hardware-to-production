## Listener transformation

Before:
“The supplier has the right machines, certifications and good samples.”

After:
“I can assess whether the actual source can repeatedly make, measure, control, trace, change and recover the required product/process.”

## Two-character opportunity

Speaker B:
“They have ISO certification, the same machine model and three perfect samples. What else do you need?”

Speaker A:
Evidence that the real source system can sustain the actual product/process claim.

## Listener tool — Supplier Capability Assessment
requirement/CTQ → process/equipment → material/sub-tier → tooling → control method → measurement → capability evidence → operator dependency → genealogy → capacity → change control → recovery → gap/action.

## Listener tool — Sample-to-Production Evidence Gap Review
What did the sample prove? Which production conditions/source/process/rate were not represented?

## Misconceptions
- certification = capability;
- same machine = same process;
- equipment list = source readiness;
- three samples = production approval;
- audit checklist is independent of CTQs;
- supplier capacity = machine nameplate;
- sub-tier is supplier’s problem only.

## Closing action
Take one critical supplier and ask them to show the exact production route, measurement method, current load and sub-tier state that will make your ramp product.

## Handoff
EP38 identifies a capable source.
EP39 turns that capability into a controlled RFQ and first-production approval package.
