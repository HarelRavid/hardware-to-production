## Listener transformation
Before: “A famous launch failure has an obvious root cause in hindsight.”
After: “I can reconstruct which claim/evidence/configuration boundary failed, what the source actually establishes, and what new evidence a corrective action must produce.”

## Two-character tension
Speaker B challenges hindsight:
“Now that we know how it failed, aren’t we just reverse-engineering a moral?”
Speaker A must reconstruct only source-supported facts and explicitly separate our framework lesson.

## Hook
Samsung Note7 replacement phones were themselves later included in the expanded recall.
Question:
What proves that a fix is actually a fix?

## Teaching flow
1. Season 6 application rule: FACT → SOURCE INTERPRETATION → OUR FRAMEWORK LESSON.
2. Note7 — corrective-action effectiveness / replacement population.
3. Tesla Model 3 — temporary less-automated mode / moving bottleneck.
4. 737 MAX JATR — cumulative/system interaction and assumption scope.
5. Peloton Tread+ — field signal aggregation / containment / legal wording.
6. Compare the cases: no universal root cause.
7. Rebuild the claim/evidence/configuration chain.
8. Practical action.

## Primary listener tool — Failure Reconstruction Sheet
Affected configuration/population
→ failed/unsupported claim
→ original evidence
→ change/out-of-scope condition
→ field event/signal
→ escape
→ containment
→ corrective action
→ new effectiveness evidence
→ remaining uncertainty.

## Attribution guards
- Samsung root cause attributed to Samsung/independent organizations presented by Samsung.
- Tesla claims attributed to Tesla SEC filing.
- JATR used only inside review scope.
- Peloton settlement preserves allegation/non-admission distinction.

## Misconceptions
- famous failure = one root cause;
- recall population = every unit defective;
- corrective action = evidence of effectiveness;
- automation = maturity;
- one regulator/company statement can be generalized beyond its scope.

## Closing action
Take one real or internal failure and fill the Failure Reconstruction Sheet without using hindsight language.
