## Listener transformation
Before: looks at admired companies and copies visible practices — additive manufacturing, co-location, Lean, partnerships — as if the practice itself caused success.
After: separates the documented change, documented outcome, plausible mechanism and transfer limit, then tests whether the mechanism fits the listener's own volume, risk, product, supplier and regulatory context.

## Narrative hook
GE did not take a twenty-piece fuel-nozzle assembly and simply print the same design faster. The product architecture changed because the manufacturing process changed.

The opening question is:

> When a famous industrialization story looks successful, what exactly are we allowed to learn from it?

## Teaching flow
1. Re-establish the Season 6 rule: success stories require stricter causal discipline than failure stories because survivorship and company-storytelling bias are strong.
2. GE LEAP: process selection became a product-architecture input; part consolidation removed joining operations but introduced a new process/qualification burden.
3. Extract pattern 1: industrialization can require product-process co-design, not scale-up of the prototype route.
4. GM + Ventec: automotive-scale manufacturing/logistics capability combined with an existing ventilator/product-domain organization.
5. Extract pattern 2: transferred capability must be named precisely; manufacturing scale competence does not automatically transfer product/regulatory authority.
6. Toyota Production System as context only: mature systems deliberately expose abnormalities and control flow, but a famous operating system is not a universal startup template.
7. Apply the Success Pattern Transfer Check to all three examples.
8. Close with the anti-survivorship rule: copy a mechanism only after identifying the evidence, dependencies and context that made it useful.

## Core framework — Success Pattern Transfer Check
Use the existing case/evidence logic, surfaced as:
`Observed practice → documented change → documented outcome → plausible mechanism → other concurrent changes → volume/risk context → regulatory/customer context → supplier maturity → CapEx/NRE context → DEV/LVP/SVP fit → transfer limit → smallest safe experiment`.

This is an internal synthesis tool, not an external industrialization standard.

## Case spine
### Case 1 — GE LEAP fuel nozzle
Owns: product-process co-design, design simplification, serial qualification of a new route.
Guardrail: GE performance/cost/life improvements are company-reported unless separately corroborated; exact numbers are optional, not the lesson.

### Case 2 — GM + Ventec ventilator scale-up
Owns: complementary capability, industrialization partnership, preservation of domain ownership.
Guardrail: pandemic emergency procurement/regulatory context limits transfer to normal NPI; do not imply automotive methods can be copied wholesale into medical devices.

### Support — Toyota Production System
Owns: context for flow/abnormality-at-source thinking.
Guardrail: do not narrate Toyota as proof that one production philosophy universally causes success.

## Listener tool — Pattern Transfer Card
For a practice the listener wants to copy, capture:
`What changed? → what outcome is documented? → why might the change matter? → what else changed at the same time? → what assumptions made it work? → which of those assumptions are true here? → which are not? → what is the smallest reversible test? → what evidence decides whether to scale it?`.

## DEV / LVP / SVP
DEV: borrow principles through reversible experiments; avoid copying expensive infrastructure before the underlying constraint is proven.
LVP: use manufacturing/quality involvement where it changes real design/process decisions; retain flexible bridge routes while volume and design remain uncertain.
SVP: production methods, supplier systems and automation must be qualified inside the actual rate/configuration/quality envelope; successful pilot behavior is not unlimited evidence.

## Prototype shortcut / expiration
Shortcut: use a familiar or low-NRE process while uncertainty is high.
Expires when: the route can no longer support the required geometry, quality, rate, cost, service or evidence claims and a more representative process must be qualified.

## Common mistakes
- copying the visible tool instead of the mechanism;
- treating a company-reported improvement as independent causal proof;
- assuming lower part count is always superior;
- confusing manufacturing competence with regulatory/product authority;
- importing high-volume automotive overhead into early LVP without an evidence/risk reason;
- using the word “best practice” without stating the applicability envelope.
