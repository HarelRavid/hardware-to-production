## Cold open

[ILLUSTRATIVE]
A printed locating jig works for ten units. Later, the contact surface wears, operators compensate by feel, and measurement drift appears.

## DEV / LVP / SVP

DEV:
improvised tooling acceptable with visible limits.

LVP:
fixtures should remove recurring rescue and create repeatable evidence.

SVP:
tooling/equipment capability, maintenance, spares and change control support intended rate.

## Misconceptions

- fixture success on a few units proves long-term capability;
- cosmetic surfaces are fine locating references;
- stiffer/more constrained fixture is always better;
- tooling does not need configuration control;
- automation fixes unstable fixture logic.

## Closing action

Choose one fixture and write the exact claim it controls, how you know it is still healthy, and what change would invalidate it.
