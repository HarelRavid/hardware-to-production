# Episode 28 Production Blueprint — Yield, Rework, Scrap and the Learning Curve

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 3 — Build the Factory Before You Need the Factory
lifecycle: Production Validation → Ramp

## Listener transformation
Before: uses final yield as the main production-health number.
After: can separate first-pass yield, rework, repair, scrap and defect recurrence to expose hidden factory rescue and prioritize learning.

## Narrative hook
Final yield is reported as 96%. The line looks healthy until the team discovers that one in three units failed first pass, was opened, adjusted and retested. Good output exists, but the process is still teaching the factory how to rescue it.

## Teaching flow
1. FPY versus final yield.
2. Rework versus repair versus scrap versus deviation.
3. Defect Pareto and recurrence.
4. Cost/time burden of poor quality.
5. Rework as hidden capacity consumption.
6. Learning curve: which interventions should disappear with maturity?
7. Link defect to process step, configuration, supplier and operator/equipment state.
8. Effectiveness: did corrective action change future populations?
9. Use yield evidence to select next closure action.

## Core framework — Yield Learning Ledger
`Unit/build population → first result → defect mode → process step/source → containment → rework/repair → retest result → time/cost burden → root-cause action → affected population → recurrence/effectiveness`.

## DEV/LVP/SVP
DEV: rescue is acceptable if recorded as learning. LVP: rescue must become visible in FPY/rework data. Ramp: recurring rework is both quality and capacity/economics debt and needs controlled closure.

## Common mistakes
- final PASS erasing first failure;
- reporting only final yield;
- mixing products/configurations into one yield number;
- treating rework as free labor;
- closing defects without recurrence/effectiveness evidence;
- using scrap reduction alone as proof of process improvement.

## Quantitative gate
Any numerical example must distinguish FPY, rolled throughput/final yield and rework load. Arithmetic must be independently audited.

## Source/evidence backlog
Quality-cost and yield terminology varies by organization; use standard statistical/quality references when externally attributed. No universal acceptable yield threshold.

## Closing handoff
Episode 28 exposes where output is being rescued. Episode 29 asks whether the system can meet demand once those losses and bottlenecks are counted honestly.
