# Episode 22 Production Blueprint — Work Instructions, Standard Work and Operator Qualification

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 3 — Build the Factory Before You Need the Factory
lifecycle: LVP → Production Validation → Ramp

## Listener transformation
Before: thinks a work instruction is a document that tells an operator what to do.
After: understands standard work as a controlled execution model combining sequence, critical parameters, visual cues, acceptance criteria, tools, safety and qualification evidence.

## Narrative hook
The inventor builds every unit correctly without looking at instructions. A new operator follows the written WI exactly and still creates defects because the document captured the visible steps but not the critical hidden decisions.

## Teaching flow
1. Difference between procedure, WI and standard work.
2. Capture sequence, inputs, outputs and critical process parameters.
3. Visual work instructions and defect exemplars.
4. Tool settings, torque/force/energy and verification points.
5. Training versus demonstrated qualification.
6. Revision/effectivity and obsolete instruction control.
7. Feedback from defects/rework into work definition.
8. When automation should replace, not merely encode, fragile human work.

## Core framework — Standard Work Definition Card
`Operation → prerequisites → sequence → critical parameter → tool/equipment → visual cue → acceptance → reaction if abnormal → qualification needed → record/traceability → revision/effectivity`.

## DEV/LVP/SVP
DEV: expert notes and videos may be enough while learning. LVP: repeatable instructions, visible critical points and operator qualification become necessary. SVP: revision control, training effectiveness, layered audits and abnormal-response discipline must scale.

## Common mistakes
- documenting nominal steps but not abnormal conditions;
- text-heavy WI with no visual evidence;
- training attendance treated as qualification;
- operators compensating for bad design/process without feedback;
- obsolete instructions remaining at point of use.

## Source/evidence backlog
ISO 9001/IATF/sector-specific competence and documented-information requirements require exact applicability before normative statements. Human-factors claims need appropriate sources.

## Closing handoff
Episode 22 defines how work should be executed. Episode 23 connects failure risk to the controls and gates that protect execution.
