# Episode 25 Production Blueprint — Layout, Material Flow and Ergonomics

status: PRODUCTION BLUEPRINT COMPLETE
season: Season 3 — Build the Factory Before You Need the Factory
lifecycle: LVP → Production Validation → Ramp

## Listener transformation
Before: treats factory layout as arranging benches and machines after the process is known.
After: can design a low-volume production cell around material flow, operator motion, WIP, safety, ergonomics, information and abnormal/rework paths.

## Narrative hook
A line has enough equipment capacity but still misses output because operators walk for parts, WIP blocks access, rework crosses normal flow and heavy units are repeatedly lifted between poorly placed stations.

## Teaching flow
1. Start from routing and product/material movement.
2. Point-of-use material and line-side presentation.
3. WIP limits and visibility.
4. Operator motion, reach, lift and repetitive-task ergonomics.
5. Safety/environmental segregation and hazardous states.
6. Normal flow versus rework/quarantine flow.
7. Information flow: travelers, status, shortages and defects.
8. LVP cell layout versus premature serial-line design.
9. Layout as changeable experiment before capital lock-in.

## Core framework — Production Cell Flow Map
`Incoming material → storage/presentation → operation → operator movement → equipment/tooling → WIP → inspection/test → abnormal/rework path → finished output → information/status signal`.

## DEV/LVP/SVP
DEV: temporary benches can work if hazards and critical handling are controlled. LVP: flow, ergonomics and material presentation should remove recurring waste/risk. SVP: layout must support rate, logistics, maintenance, safety and controlled abnormal flows.

## Common mistakes
- optimizing equipment position but ignoring operator/material travel;
- hiding WIP as “buffer” everywhere;
- rework flowing backward through normal stations without identity/control;
- buying conveyors/automation before the routing stabilizes;
- treating ergonomics as comfort rather than quality/safety/capacity input.

## Source/evidence backlog
Ergonomics, machinery safety, EHS and hazardous-material requirements are jurisdiction/industry specific and must be scoped before normative claims.

## Closing handoff
Episodes 20–25 have built the production system. Episode 26 now uses that system in a deliberately designed pilot build.
