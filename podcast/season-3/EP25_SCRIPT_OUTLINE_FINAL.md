## DEV / LVP / SVP

DEV:
temporary benches can be fine if hazards/critical handling are controlled.

LVP:
remove recurring movement/risk and expose flow.

SVP:
layout supports rate/logistics/maintenance/safety/abnormal flow.

## Misconceptions

- shortest equipment distance automatically gives best flow;
- all WIP is bad;
- all buffer inventory is capacity;
- ergonomics is only comfort;
- conveyor/automation should be added before routing stabilizes;
- local motion improvement guarantees system throughput.
