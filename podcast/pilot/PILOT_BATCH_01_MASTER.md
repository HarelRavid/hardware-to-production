## What the pilot proved

### Technical
- claim registers work across episode types;
- P0 claims remain visible without falsely implying verification;
- source-vs-synthesis separation is practical;
- applicability can be stated without turning episodes into standards manuals;
- quantitative examples can be isolated for independent QA;
- no pilot episode contradicts V1 global invariants.

### Audience
- DEV/LVP/SVP framing works;
- prototype shortcuts can carry explicit expiration conditions;
- listener tools turn knowledge into action;
- episodes can support independent entry points rather than a mandatory 68-episode sequence.

### Navigation
- season placement is useful;
- prerequisites can remain limited;
- short recap contracts allow multiple listener routes;
- topic tracks can act as deep dives without replacing seasons.

### Production workflow
- one template can scale with conditional modules;
- unresolved evidence remains visible;
- CLAIM SET STABLE is now explicitly separate from EVIDENCE VERIFIED;
- episode density must be controlled by selecting core on-air claims.
