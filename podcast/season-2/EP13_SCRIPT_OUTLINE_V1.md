## Listener promise
Compare machining, casting, forging/forming, sheet and near-net + finish-machining routes using material state, defect mechanisms, dimensional behavior, inspection and economics rather than familiarity.

## Cold open
[ILLUSTRATIVE]
A machined aluminum prototype survives testing. A cast or forged production route is proposed and suddenly porosity, grain flow, heat treatment, residual stress and distortion matter.

## Listener tool — Metal Route Matrix
Load/function → alloy/state → geometry/section → route family → defect/variation → thermal/material-state change → machining/finish allowance → inspection/NDT → volume/tooling → supplier evidence.

## Misconceptions
- machining is the safest/default production route;
- same alloy name means same state/properties;
- casting porosity is one simple defect;
- forging is always stronger;
- machine positioning spec = part tolerance;
- formed sheet follows CAD after tool release.

## Closing action
For one metal part, write the exact material state delivered by each candidate route, not only the alloy name.
