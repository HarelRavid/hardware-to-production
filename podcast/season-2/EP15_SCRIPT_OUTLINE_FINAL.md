## Two-character opportunity

Rona:
“If the supplier uses the same carbon fiber and the same resin, why isn’t it the same material?”

Oz:
Because orientation, layup, cure/consolidation, process defects and tooling help create the realized material state.

Recurring challenge:
“Why doesn’t a strong coupon prove the part?”

## Cold open

[ILLUSTRATIVE]
A hand-laid carbon cover is light and stiff. A production supplier uses the same nominal fiber/resin family, but local orientation, cure and defect state differ and the part behaves differently.

## Beat 1 — Composite = system, not trade name

Claims: EP15-C01/C02.

Reinforcement
+ matrix
+ reinforcement form
+ orientation/stacking
+ process/cure/consolidation
= realized composite state.

## Beat 2 — Route families

High-level only:
- hand/wet layup;
- vacuum bag/infusion;
- prepreg/autoclave/OOA;
- RTM/closed mold;
- compression molding/SMC/BMC;
- filament winding/pultrusion;
- ATL/AFP where relevant.

Guard:
no maturity ranking.

## Beat 3 — Orientation and stacking are structural definition

Claim: EP15-C03.
Sources: ASTM D3039 / ISO 527-5 context.

Use load-path example:
0° reinforcement good for one load path can be weak for another.

Do not teach laminate-design recipes.

## Beat 4 — Storage / handling / cure / consolidation

Claim: EP15-C04.
Source: CMH-17 public scope.

Teach:
material lot/history, layup process, bagging/consolidation, cure record and tool state may matter.

No cure recipe.

## Beat 5 — Defects are process-created

Claim: EP15-C05.

Examples:
void / dry area / resin-rich area / wrinkle / delamination / misorientation / contamination.

Guard:
not all defects have same significance; consequence is part/material/load/location specific.

## Beat 6 — Coupon ≠ part

Claims: EP15-C06/C07.

Use ASTM D3039 public significance:
test result is tied to material, layup, stacking, conditioning, void content, reinforcement fraction and test state.

Run Coupon-to-Part Transfer Check:
- same architecture?
- same thickness?
- same cure/process?
- same defect population?
- same environment?
- same loading?
- representative inspection?

## Beat 7 — Tooling and dimensional state

Claim: EP15-C08.

Explain:
tool thermal behavior, consolidation, cure shrinkage/spring-in and geometry can move final shape.

Keep mechanism conceptual.

## Beat 8 — Secondary operations matter

Claim: EP15-C09.

Trim / drill / inserts / bonded joints can introduce:
damage / delamination / load-transfer changes / inspection needs.

Callback to EP14 joining, without re-teaching it.

## Beat 9 — Inspection / NDT

Claim: EP15-C10.

Teach:
inspection method should match defect/material/geometry/criticality.

No universal NDT winner.

## Beat 10 — Change / supplier equivalency

Claim: EP15-C11.

Same trade name or nominal material family does not automatically preserve evidence after:
- supplier change;
- prepreg form change;
- process route change;
- cure/tooling change.

Use CMH-17 equivalency concept only as scoped corroboration.

## Misconceptions

- carbon fiber is one material;
- same resin/fiber trade name means same part behavior;
- coupon strength equals part allowable;
- autoclave automatically means “best” or “most mature”;
- NDT can inspect every relevant composite defect;
- supplier/process change is equivalent if nominal material name is unchanged.

## Closing action

For one composite part, write the exact architecture/process state that created the current evidence — not just the material name.
