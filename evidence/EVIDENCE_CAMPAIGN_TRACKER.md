## A4 — Breadth result
Quality foundations now has a source-backed backbone for PFMEA->Control Plan, measurement-system characterization, SPC, capability assumptions, sampling/100% inspection boundaries and reaction-plan logic.

## A5 — Current findings
Backbone captured so far:
- NASA PRR criteria showing production readiness is about efficiently producing the required number of units with production plans, controls, resources, documentation and production configuration;
- NIST MEP case evidence linking FPY/rework reduction to processing time, lead time and released capacity;
- Lean Enterprise Institute definitions separating takt time and cycle time;
- process-capacity methods that evaluate linked resources to identify bottlenecks;
- ASQ FPY definition separating first-pass flow from eventual recovery through rerun/retest/repair.

Editorial conclusions now support:
1. pilot/PVT must test the production system, not only product function;
2. production representativeness is multidimensional;
3. one successful build is weak evidence of repeatability;
4. takt, cycle time, throughput, lead time and capacity are different concepts;
5. yield/rework affect flow and capacity, not only cost/quality reporting;
6. meeting takt briefly does not automatically prove sustainable production rate;
7. final yield can hide unstable first-pass flow.

Remaining A5 breadth gaps:
- sustained rate/run-at-rate evidence;
- stronger bottleneck/constraint and queue/WIP sources;
- ramp/learning-curve evidence;
- engineering-change cut-in/effectivity during ramp;
- sector/company-specific meaning of PVT/pilot nomenclature;
- stronger case-study set for Episodes 26–31.

## Campaign rule
Breadth pass does not attempt exhaustive research. Each package must first identify:
1. authoritative source families;
2. episode-critical claims;
3. claims with weak/GNR evidence;
4. applicability conflicts;
5. Pass-2 depth targets.

## Promotion rule
A package moves from IN PROGRESS to BREADTH COMPLETE only when all five items above are represented and the strongest primary sources are captured or explicitly unavailable.
